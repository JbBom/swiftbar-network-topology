# Network Baseline Monitor

> Detect whether the current network environment has drifted from a trusted baseline.

## Goal

Monitor whether the current network environment has drifted from a user-confirmed trusted baseline.

## v0.1 Scope

### Included

- Public IPv4
- Country / region
- ASN / ISP
- DNS resolver
- IPv6 availability
- Trusted baseline
- Drift comparison
- SwiftBar status output

### Not included

- Browser fingerprint
- Docker isolation
- Claude Code inspection
- MCP permission checks
- API key scanning
- IP reputation score
- Account risk prediction
- Anti-fraud or anti-ban logic
- VPN/proxy management
